Part Two: IDE Installation

The IDE is portable; you can directly extract the IDE compressed package to any location on your work computer and run the
CodeCanvas.exe executable program.

During the IDE launch process, you will be prompted to select a workspace; you can specify a custom path.

Note:

 The IDE currently only supports Windows 10 and later operating systems.

 Avoid using Chinese characters or spaces in the extraction and workspace paths.

p7

Part 3: Example Program Import

For your convenience, we have prepared a simple LED flashing program, Hello_LED, in the SDK directory.

Open the IDE menu and select File -> Open Projects from File System or Archive. Click Directory

picture

Select the Hello_LED folder under the SDK directory.

picture

Click the Finish button to import the project.

picture

4. Board Connection
Connect your board to your computer using the emulator. Pay attention to the cable connection between the emulator and the board.

Connect the power adapter to the board and power it on. Press the power switch on the board to turn it on.

p9

picture

5. Program Compilation
Right-click the project, click "Build Project" to compile the project, generating an ELF binary file. The program compilation is successful.

p10

6. Running the Program
Right-click the project, click Run As -> Application with GDB and OpenOCD.
In the pop-up window, click Run to burn the program to the board and execute it.

picture

7. Observe the board. Check the board; the LEDs will start flashing in an orderly manner.
