1. Overview

1.1 Introduction to the FDM320RV335 Software Library

The FDM320RV335 Software Library is a highly optimized collection of application functions written for FDM320RV335.

It is divided into:

- Digital Signal Processing Software Library
- Mathematical Library

The DSP software library is further divided into:

- Floating-point library
- Fixed-point library

The library fully utilizes the floating-point processing unit and fixed-point processing unit of FDM320RV335.

For user convenience, each function includes:

- Assembly implementation
- Reference implementation
- Example program using the function

All functions have been validated on FDM320RV335.

1.2 Software Library Directory Structure and Usage

The structure of the FDM320RV335 software library is shown in Figure 1-1.

- performance: example applications for functions
- source: assembly implementations of functions

Assembly programs, reference programs, and sample programs share the same structure.

dsp contains the DSP software library, including:

- fixed-point library
- floating-point library
- FFT functions
- Filter functions
- Vector functions

math contains the mathematical software library, including:

- Trigonometric functions
- Inverse trigonometric functions
- Logarithmic functions
- Exponential functions

2.1.1.5 FFT32_init

Function Description:

The FFT initialization routine updates the twiddle-factor pointer using the address of the twiddle-factor table.

Twiddle factors are stored at the address pointed to by tfptr.

The table contains up to 3072 entries (32-bit words), supporting complex FFT calculations up to 4096 points.

The table contains:

3N / 4 entries

where N is the maximum supported FFT size.

Function Prototype:

void FFT32_init(CFFT32_Handle);

Function Parameters:

Definition of CFFT32_Handle is shown in Section 2.1.1.1.

Function Return Value:

No return value.

Its result is used to update the twiddle-factor table pointer tfptr in CFFT32.

Real Fast Fourier Transform (RFFT).
