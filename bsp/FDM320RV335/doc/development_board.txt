2. Functional Block Diagram

The functional block diagram of FDM320RV335 is shown in Figure 2-1.

<picture_1>

Figure 2-1 FDM320RV335 Functional Block Diagram

All components of FDM320RV335 are connected to the system bus. The main masters include the DSP subsystem and


p9
Datasheet FDM320RV335

7

DMA.

The DSP subsystem includes the RISC-V architecture SpringCore1.0, independent internal storage units, timers, interrupt controller, and debug unit.

When SpringCore1.0 initiates an access, the internal bus of the DSP subsystem first determines the address. If the address belongs to the subsystem internally, the access is completed internally. Otherwise, the internal bus sends the access request to the system bus, where the access is completed under system bus arbitration.

Before DMA initiates access as a master, it first receives configuration from SpringCore1.0 as a slave, after which DMA initiates access.

Slave devices accessible by DMA include: data storage units inside the DSP subsystem, ADC result registers, and ePWM + HRPWM registers.

All peripherals perform system access and configuration to the DSP subsystem through the interrupt controller (PLIC). PLIC accepts multiple external interrupt sources, arbitrates them, and generates one external interrupt signal to the DSP subsystem.

4. Device Detailed Description

4.1 FDM320RV335 Processor Core

The FDM320RV335 processor core is a RISC-V compatible, high-efficiency, low-cost 32-bit processor for embedded applications.

FDM320RV335 adopts the RV32IMFC-Ext instruction set architecture and is mainly targeted at high-performance real-time signal processing fields such as digital power supply and motor control.

Main features of the FDM320RV335 processor core:


p34
Datasheet FDM320RV335

32

1) RISC-V architecture.

2) Supports integer and fixed-point computation types.

3) Supports 32-bit single-precision data type.

4) Supports 32 general-purpose integer registers X0–X31.

5) Supports 32 floating-point general-purpose registers F0–F31.

6) Hardware RAW and WAR dependency detection.

7) Supports RISC-V Debug 0.13.2 debugging standard, including breakpoints, single-step and similar operations.

8) Customized instructions accelerate key performance paths.

9) Fast context switching for real-time processing acceleration.

10) 16-bit compressed instructions.

Independent memory spaces:

1) Private high-speed program space PMEM and data space DMEM.

2) External masters may initialize DMEM.

3) 32-bit addressable space.

1) IFU: Instruction Fetch Unit, responsible for instruction fetching, including handling of incoming interrupts and branch instructions, as well as core exceptions and pipeline front-end processing.

2) IDU: Instruction Decode Unit, responsible for instruction decoding and dispatching instructions to functional units.

3) IXU: Integer Execution Unit, responsible for integer / fixed-point ALU computations.

4) FXU: Floating Execution Unit, responsible for single-precision floating-point ALU computations.

5) LSU: Load Store Unit, responsible for memory load/store operations, address calculation, etc.

6) XRF: X Register File, stores integer data.

7) FRF: F Register File, stores floating-point data.

8) PMEM: Program Memory.

9) DMEM: Data Memory.
